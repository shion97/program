# UHFによる一次元Hubbard鎖のソリトン計算

一次元Hubbard模型を非制限Hartree–Fock（UHF）近似で解くJuliaスクリプトです。
反強磁性の初期密度の一部でup/downを交換し、ドメイン壁を含む状態からSCF計算を始めます。
ソリトンの安定性や収束先は計算条件に依存し、初期状態を与えるだけで保存が保証されるものではありません。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `uhf.jl` | 設定、初期密度作成、UHF計算、CSV・レポート・グラフ保存をまとめた実行ファイル |
| `test/runtests.jl` | 計算関数、境界条件、load実行と結果保存の回帰テスト |
| `README.md` | 構成、実行方法、現在の制約とテスト整理の記録 |

専用の`Project.toml`・`Manifest.toml`はありません。入力CSVや計算結果も同梱していません。

## 実行方法と設定

Juliaと`Plots`を利用できる環境で、プロジェクトのディレクトリから実行します。
`LinearAlgebra`、`DelimitedFiles`、`Printf`も使用します。

```powershell
julia uhf.jl
```

設定は`uhf.jl`冒頭の「計算設定」を編集します。コマンドライン引数はありません。

| 設定 | 現在の値 | 意味 |
| --- | --- | --- |
| `L`, `t`, `U` | `50`, `1.0`, `4.0` | サイト数、最近接ホッピング、オンサイト相互作用 |
| `N_up`, `N_down` | `25`, `25` | 各スピンの粒子数（half-filling） |
| `boundary` | `"PBC"` | 周期境界条件。`"OBC"`なら開放境界条件 |
| `initial_mode` | `:manual` | コード内で初期密度を作成。`:load`ならCSVから読み込み |
| `input_csv` | `"results_vault/反強磁性/density_checkpoint.csv"` | load時の入力。相対パスは実行時の作業ディレクトリ基準 |
| `result_dir_name` | `"soliton"` | `results_vault/soliton/`へ保存。`nothing`なら`outputs/` |
| `mixing`, `tol`, `maxiter` | `0.25`, `1e-8`, `10_000` | 密度混合率、残差の収束閾値、最大反復回数 |

manual初期化では、平均密度の周囲に交互のスピン偏極を加え、`up0[5:30]`と`down0[5:30]`を交換します。
現在の50サイト・PBCでは、この区間の両端に交互配列の位相が切り替わるドメイン壁を導入します。
範囲は固定なので、manualで`L < 30`にすると範囲外アクセスになります。
サイト数・粒子数・交換区間を変える際は、各密度が0〜1、総和が各スピンの粒子数になることも確認してください。
`solve_uhf`自体は、妥当な初期密度を渡せば他のサイト数・粒子数でも利用できます。

load用CSVは先頭行がヘッダーで、以下の3列を持ちます。データ行は`L`行、siteは1から`L`の順です。

```text
site,n_up,n_down
1,0.4,0.6
2,0.6,0.4
```

入力ファイルは指定パスから読み、出力先にある同名CSVへ自動で切り替えることはありません。

## 計算処理と関数

平均場ハミルトニアンは`h_up = h0 + Diagonal(U .* n_down)`、
`h_down = h0 + Diagonal(U .* n_up)`です。各スピンの低い固有値から指定粒子数だけ占有し、サイト密度を更新します。
残差は、更新前後の密度差の絶対値を全サイト・両スピンで最大化した値です。
未収束なら`(1-mixing) * 入力密度 + mixing * 出力密度`を次の入力にします。
全エネルギーは運動エネルギーと`U * sum(n_up .* n_down)`の和です。

| 関数 | 役割 |
| --- | --- |
| `result_directory`, `abs_path` | 出力ディレクトリとファイルパスの決定。出力ファイル名のディレクトリ部分は除去 |
| `print_result`, `write_initial_conditions` | 端末・レポートへの記録。manualでは初期密度作成コード、loadでは入力相対パスを記録 |
| `validate_density` | 配列長、有限値、0〜1の範囲、粒子数を検証 |
| `save_density`, `load_density` | サイト密度のCSV保存・読み込み |
| `site_density`, `output_density` | 占有軌道からの密度計算と平均場ハミルトニアンの対角化 |
| `hf_energy` | エネルギー計算と固有値を用いた恒等式による検算 |
| `solve_uhf` | SCF反復。密度、電荷、磁化、軌道エネルギー、エネルギー、残差、反復履歴を返す |
| `plot_density_magnetization`, `plot_orbital_energies` | 電子密度・局所磁化の対と、軌道エネルギー準位図を作成して返す |
| `plot_staggered_magnetization` | 初期・最終状態のスタッガード磁化を同じ図に描画 |
| `save_plots` | SCF履歴、軌道エネルギー準位図、初期・最終状態の電子密度と局所磁化、スタッガード磁化の比較を描画・保存 |
| `run_calculation`, `main` | 初期化から計算・結果保存までの実行処理 |

`include("uhf.jl")`では自動計算せず、ファイルを直接実行した場合に`main()`が呼ばれます。
`Plots`の読み込みはinclude時にも行われます。

## 出力

既定では実行時の作業ディレクトリに`results_vault/soliton/`を作成し、次を保存します。
同じ設定で再実行すると同名ファイルを上書きします。

| ファイル | 内容 |
| --- | --- |
| `density_checkpoint.csv` | 最終の`site,n_up,n_down`。再開用の入力にも利用可能 |
| `uhf_results.txt` | 計算条件、初期化方法、各反復・最終結果、収束状態 |
| `scf_energy.png` | SCF全エネルギー履歴 |
| `scf_residual.png` | SCF残差履歴（対数軸） |
| `final_orbital_energies.png` | up/downを左右に分けた最終軌道エネルギー準位図。各準位を水平線で表し、横軸のラベル・目盛りは表示しない |
| `initial_density_magnetization.png` | SCFに渡す初期状態の電子密度`n_up + n_down`（上段）と局所磁化`n_up - n_down`（下段）。共通のサイト軸で表示 |
| `final_density_magnetization.png` | 最終状態の電子密度（上段）と局所磁化（下段）。初期状態と同じ形式で表示 |
| `staggered_magnetization.png` | サイトごとのスタッガード磁化`(-1)^i * (n_up[i] - n_down[i])`を比較。initialは灰色点線、finalはオレンジ実線 |

端末と`uhf_results.txt`では、各反復と最終集計の全・運動・相互作用エネルギー、および最終集計のエネルギー差を、元の Float64 値に読み戻せる桁数で出力します。
`delta_E = E - E_compared`、`delta_E_kin = E_kin - E_kin_compared`、
`delta_E_int = E_int - E_int_compared`で、正なら参照状態より高い値です。未収束時も最後に再評価した結果との差を出力します。
参照値は、OBC の位相欠陥なし状態 `soliton_nothing` を混合率 0.25 と収束閾値 1e-8 で計算した最終集計値です。

スタッガード磁化はサイト番号`i=1`からの`(-1)^i`を用い、既存の局所磁化と同じ規約で1/2を掛けません。manual・loadのいずれでも、SCF更新前の初期密度と最終密度を重ねて表示します。

manual・loadのどちらでも、初期化後・SCF更新前の密度を初期状態として描画します。
局所磁化だけの`final_magnetization.png`は今回から生成しません。
数値誤差を拡大せず初期・最終状態を比較できるよう、電子密度の縦軸は0〜2、局所磁化は−1.5〜1.5に固定します。
局所磁化の凡例は、初期・最終ともにグラフ内の右上に置きます。局所磁化の物理的範囲−1〜1の外に余白を設け、データとの重なりを防ぎます。

最大反復回数に達して未収束でも、最後の混合密度から再対角化した結果を保存します。
利用時はレポートの`converged`と`residual`を確認してください。
現行のCSV保存はBOMなしです。

## 保存レポートのエネルギー差を比較する

```powershell
julia plot_energy_differences.jl
```

スクリプトと同じディレクトリの `results_vault` を再帰的に検索し、各 `uhf_results.txt` の
`delta_E`・`delta_E_kin`・`delta_E_int` を読み込みます。SCF計算や差の再計算は行いません。
各結果フォルダを1グループとし、全・運動・相互作用エネルギー差の点を縦方向に少しずらした
グループ化ドットプロットを作成します。3種類は色とマーカーで区別し、線では結びません。
`results_vault/energy_differences.png` に保存します。同名画像は再実行時に上書きします。
横軸はエネルギー差、縦軸は `results_vault` からの相対フォルダ名（辞書順、上から下）です。
エネルギー差ゼロの縦の基準線を表示します。
正の値は参照状態より高いことを表します。参照値や計算条件の一致は入力レポート側で確認してください。

3種類の差がそろわない古いレポートは警告して除外します。値が不正・非有限の場合や、
読み込み対象がない場合はエラーにします。`converged=false` の結果は凡例でなく縦軸の
`(unconverged)` で区別します。元のtxtは変更しません。

個別検証は `julia test/plot_energy_differences.jl` で実行します。
公開関数 `read_energy_differences` によるtxtの読み取りと、
`plot_energy_differences` によるグループ化ドットプロットの描画・PNG保存を検証対象とします。
2026-11-09に軸の入れ替え後の個別テスト19件が成功し、実際の4件のレポートから生成したPNGの表示も確認しました。
`soliton_nothing` は差の記録がないため警告して除外されます。
独立した描画スクリプトの追加のため、SCF計算と既存の全テストは再実行していません。

## テストの範囲と整理

```powershell
julia test/runtests.jl
```

エネルギー差の出力だけを検証する場合は`julia test/energy_comparison.jl`を実行します。
`U=0`・2サイトOBCの既知のエネルギーを使い、収束・未収束の両方で端末とtxtの差の値・符号を確認します。

テストは描画をヘッドレスに設定し、入出力の検証には一時ディレクトリを使います。
プロジェクト内の計算結果を作成・上書きしません。

流用元の「manualで3サイト・half-filling以外を計算する」テストは削除しました。
現在のmanual初期化はサイト5〜30の交換が目的であり、このテストが仮定する小サイズ初期化と両立しないためです。
次のテストは現行コードにも関係するため残しています。

- `U=0`の既知のエネルギーと各スピンの粒子数（空・全占有を含む）。
- PBC/OBCの軌道エネルギー、小サイズPBC、不正な境界条件の拒否。
- load時の入力パス選択、入力ファイルの保持、収束・未収束時の保存。
- レポートの条件・結果、CSV往復、6種類のPNG出力。
- スタッガード磁化の初期・最終値、initialの灰色点線とfinalのオレンジ実線。
- 描画する電子密度・局所磁化の値と縦軸範囲、軌道準位線の値と横軸目盛りの非表示。
- 入力欠落時のエラー、入力だけある場合の実行、絶対入力パスの相対表記。

manualの50サイト・ドメイン壁生成、ソリトン解の物理的安定性、PNGの見た目は、この自動テストでは検証していません。

2026-11-06にJulia 1.13.0の既存環境で変更後のテストを実行し、102件が成功しました
（粒子数12件、境界条件9件、密度・磁化の描画8件、準位図8件、load・結果保存65件）。
既定のmanual・50サイト・PBCの計算も別の出力先で実行し、108反復での収束と、初期・最終の密度・磁化および準位図の見た目を確認しました。
依存パッケージの追加は行っていません。

スタッガード磁化追加後の検証（2026-11-06）：113件中111件成功。追加した描画9件と、収束・未収束時のPNG保存は成功し、4サイトの比較画像の見た目も確認しました。既存の電子密度テスト2件は、現在のコードが`n_i - 1`・縦軸−0.001〜0.001を表示する一方、テストが以前の`n_i`・縦軸0〜2を想定しているため失敗します。この既存表示とテストは今回変更していません。
