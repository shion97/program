# 実験条件一覧

全条件をOBC・PBCの両方で試す。表の1行は、境界条件の異なる2ケースに対応する。

## 共通設定

| 項目 | 設定 |
|---|---|
| モデル・近似 | 1次元Hubbardモデル・UHF |
| サイト数 L | 50（固定） |
| ホッピング積分 t | 1.0 |
| 境界条件 | OBC、PBC |
| 温度 | T=0 |
| 外部電場 | なし |
| tol | 10⁻¹⁰（固定） |
| maxiter | 10000（固定） |

全電子数は Ne=N↑+N↓、スピン偏極は ΔN=N↑−N↓ とする。
初期密度は、各スピンについて総和がNσに一致し、各サイトで0≤nᵢσ≤1を満たすように設定する。

## 計算数と原資料で未指定の条件

新規計算は計40ケース（OBC・PBCの20組）。再利用する条件は再計算しない。

再利用する結果は、再利用先の実験にも6ファイルをコピーして配置する。再利用を含む結果は全56ケース分となる。

原資料には、半充填・スピン非偏極以外での反強磁性型初期密度の具体式、磁区壁型の具体式・位置、ランダム型の生成方法・振幅・シード値は指定されていない。

## 追加グラフ

各実験でOBCとPBCの全エネルギー差（E_PBC−E_OBC）の比較グラフ `boundary_energy_difference.png` を1枚作成する。全8実験で計8枚とする。

`julia plot_boundary_energy_difference.jl`で、保存済みの`uhf_results.txt`から8枚を再生成する。入力・出力先はこのJuliaファイルと同じフォルダの`results_vault/`とし、実行時のカレントディレクトリには依存しない。

最終結果の`E`を読み取り、OBC・PBCの両方が`converged=true`かつ最終残差が記録された`tol`未満の場合に限り、PBC−OBCを描画する。境界条件以外の計算パラメータが一致しない場合、入力が欠けている場合、不正なログの場合は、PNGを更新する前にエラーとして停止する。

全条件を横軸の目盛りに表示し、収束した組の差を点で示す。未収束の組は差を描画せず、その条件の位置に`NC`と表示する。実験5はΔN=0・4を区別する。条件間を線で結ばない。

この処理はSCFの再計算を行わず、既存の8枚のPNGだけを上書きする。入力ログの全エネルギーは小数点以下12桁で記録されているため、描画の再現精度もその記録精度に従う。

検証は`julia plot_boundary_energy_difference.jl --test`で実行する。テストはファイルを生成しない。対象実験・条件名・横軸の設定は、Juliaファイル内の`experiment_specs`にまとめる。実験条件を変更する場合は、この一覧と同関数を併せて更新する。
