# UHF計算

`uhf.jl`冒頭の計算設定・初期密度を編集し、`julia uhf.jl`で実行します。
既存のJulia環境の`Plots`を使用します。

## 出力

`uhf.jl`冒頭の`result_dir_name`で保存先を切り替えます。
パスの基準は実行時のカレントディレクトリです。

```julia
result_dir_name = nothing       # 試験用: outputs/
```

結果を残す場合は、保存するフォルダ名を指定します。

```julia
result_dir_name = "反強磁性"    # 保存用: results_vault/反強磁性/
```

フォルダ名には区切り文字を含まない名前を指定します。
保存先フォルダは自動作成します。同じ保存先にある同名ファイルは実行ごとに上書きするため、
別の結果を残す場合は異なるフォルダ名を指定してください。
`initial_mode = :load`の場合、`input_csv`を実行ディレクトリからの相対パスで指定します。
例えば`input_csv = "results_vault/反強磁性/density_checkpoint.csv"`と指定します。
入力CSVは保存先とは独立して読み込み、同名のCSVが保存先にあっても代わりに読み込むことはありません。
絶対パスも使用できます。テキストへの記録は実際の入力ファイルの相対パスです。
既存ファイルは自動移動・削除しません。

選択した保存先へ、次のファイルを保存します。

| ファイル | 内容 |
| --- | --- |
| `density_checkpoint.csv` | 再開用のサイト別スピン電子密度 |
| `scf_energy.png` | SCF反復ごとの全エネルギー |
| `scf_residual.png` | SCF反復ごとの残差 |
| `final_orbital_energies.png` | 最終評価のスピン別ハミルトニアンの固有値 |
| `final_magnetization.png` | サイト別磁化 |
| `uhf_results.txt` | 初期条件・反復履歴・最終結果（UTF-8） |

`uhf_results.txt`の冒頭には、「パラメータ」の`L`、`t`、`U`、`m`、`N_up`、`N_down`と、
「計算の設定」の`mixing`、`tol`、`maxiter`を実行時の値で記録します。
初期電子密度については`initial_mode`に加え、manualでは`uhf.jl`内のmanual分岐のコードを
コメントも含めて記録します。loadでは実際に読み込むCSVの、実行ディレクトリからの相対パスを記録します。
`Saved:`の保存先案内はターミナルだけに表示し、テキストには記録しません。

軌道エネルギー図は、横軸をエネルギー昇順の軌道番号、縦軸を固有値とします。
最大反復回数までに収束しなかった場合も、最後の混合密度から再評価した結果をCSV・PNGに保存します。
ターミナルとテキストに`converged=false`と未収束の案内を表示します。
収束した場合は`converged=true`と表示します。反復履歴も引き続き保存します。
入力不備やファイル書き込みエラーなどは、従来どおりエラーとして扱います。

## テスト

`julia test/runtests.jl`で実行します。Julia標準の`Test`と既存の`Plots`を使用します。
一時ディレクトリに入力CSVを作成し、指定パスの読み込み、初期条件・結果の記録、
収束時・未収束時のCSVとPNG保存、入力ファイル不在時のエラーを検証します。
既存の計算結果や`uhf.jl`の設定値は書き換えません。
