# OBC反転区間の再置き換え

置き換え対応: 7–44 → 5–46、11–36 → 13–38、3–40 → 3–44、3–28 → 3–36。
PBCと指定外のOBC結果は保持する。
条件: L=50, t=1.0, U=4.0, N_up=N_down=25, OBC、既存manual初期密度、mixing=0.25, tol=1e-8, maxiter=10000。
参照値: E_compared=-23.013070703721、E_kin_compared=-43.110713154683、E_int_compared=20.097642450963。
現在のuhf.jlの反転区間と保存先だけを変えたコピーを、各新規結果フォルダのuhf_run.jlとして保存する。
出力先は ../UHF_soliton_OBC/results_vault/soliton_<始点>-<終点>/。CSVはUTF-8 BOM付き。
数値はレポートの出力値を追加の丸めなしで使用する。

完了条件: 新規4件の収束、residual<tol、粒子数（既存許容差1e-8）、エネルギー内訳と差（小数12桁出力の丸め幅内）、CSV・6種類のPNG・最終交代磁化の符号反転位置を確認する。
検証後に旧4結果フォルダを削除し、指定外の結果と元プログラムのSHA-256保持を確認する。
数値計算実装の変更はないため、単体テストは追加せず実計算結果を検証する。
