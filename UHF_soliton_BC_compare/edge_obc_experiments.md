# OBC端付近の追加計算

条件: L=50, t=1.0, U=4.0, N_up=N_down=25, OBC。
初期密度、mixing=0.25、tol=1e-8、maxiter=10000は既存uhf.jlに従う。
16・20・24サイト反転を、始点3の区間3–18、3–22、3–26で比較する。
3–26は既存の収束済み結果を再利用し、3–18と3–22を追加計算する。
OBC反強磁性状態 E_AF=-23.013070703721 を比較基準とする。
既存uhf.jlを変更せず、区間と出力名だけを変えた実行用コピーを新規結果フォルダに保存する。
完了条件: 収束、粒子数、エネルギー内訳と差の整合性、最終交代磁化の符号反転位置を確認する。
